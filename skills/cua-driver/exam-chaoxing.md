# 学习通（超星）考试页答题实战

本文件是 cua-driver skill 的场景子文件，专门记录"作答学习通（chaoxing / mooc）在线考试"时的踩坑与可行路径。

## 前提：通道选择

- 如果浏览器开启了**垂直标签页**，`cua_browser_prepare`（CDP 附着）可能报 `browser_wrong_target_refused`（"native tab strip did not expose one exact structural new-tab action"）。**不要纠结，直接走 UIA 路由**（见 SKILL.md "浏览器（CDP 路由）" 第 4 条）。
- 通道纪律：整个考试任务只用 `cua_*`（PostMessage/UIA 后台通道），不要切到 `computer_*`（SendInput 前台）。

## 答题流程（验证可行）

1. **定位窗口**：`cua_list_windows` 拿到浏览器进程（如 `msedge.exe`）的 pid + window_id。
2. **读当前题**：`cua_get_window_state` 的 UIA 树里，网页正文会被投影成若干 Text 节点。注意：正文会被**写有姓名和学号的水印行刷屏**（同一段"姓名 + 学号"的 Text 行会反复出现几十次），读题时忽略这些行。
3. **点选项**：用 `cua_click`（element_token，`s000000XX:N` 形式）点击 RadioButton。UIA 节点里选项的标签是 "A はこ" / "B なら" / "C や" / "D たた" 这种"字母 + 选项文本"的拼接形式，**字母在前缀**，匹配时带上完整文本。
4. **推进到下一题**：点击 `Hyperlink "下一题"`（value 是 `javascript:;`）。每次点完"下一题"后 UIA 树刷新，**旧 element_token 立即作废**，必须重新读。
5. **批量推进**：用 `cua_run_steps` 把"点选项 + 点下一题"串成一组，`expect` 用下一题的第一个选项名称做"题号已前进"的断言（例如 `expect [{"name":"A かか","role":"radiobutton"}]` 表示已经进入下一题）。

## 高效路径：先整卷预览，再回填

逐题模式的问题：每切一题都要重读 UIA 树，正文又碎又长，容易漏题、误读。已验证更稳的做法：

1. 在考试页点右上角"整卷预览"按钮（`Hyperlink "整卷预览"`），进入预览页。
2. 预览页会**把所有题目全部展开**（题数以页面实际显示为准，不一定是 25 题），每个选项仍是 RadioButton，可以一次性读全。
3. 读全后，对照"整卷预览"里每题的选项，把答案规划好。
4. 回到"考试"页（点"上一题"或题号跳回），逐题回填，用 `cua_run_steps` 批量提交。
5. 回填时，**每跳题用 `expect` 断言当前页出现了下一题的第一个选项**，再点选项 + "下一题"，避免"题没跳就点选项"。

## 关于题目正文碎片化

- UIA 树里，题目正文被拆成多个 Text 节点（题号 + 题干 + 选项标签 + 水印），且水印行（姓名 + 学号）会**以几十次的重复**铺满整棵树。
- **不要依赖逐 Text 节点拼接正文**——容易漏、容易卡。优先用"整卷预览"页（正文连续、水印行相对少）一次性读完。
- 如果只能逐题读，把"已作答"状态（题号旁的绿色标记）作为"这题没漏"的信号，而不是"选项是否点中"的信号。

## 选项匹配陷阱

- UIA 节点标签是 "A はこ" 这种"字母 + 文本"拼接，**匹配时带上前缀字母**（`name="A はこ"`），不要只写 "はこ"。
- 如果选项里含 `、`（如 "A で、が"），UIA 标签会原样带逗号，匹配时也带上。
- "下一题" / "上一题" 是 Hyperlink，value 是 `javascript:;`，**用 name 匹配，不要用 value**。
- 题号 ListItem 可点，用于跳题；同样用 name 匹配，**题号数量以页面实际显示为准**（不一定是 1–25）。

## 提交前检查

- 默认**作答完毕停在当前页，不代提交**："交卷"（预览页右上角的"交卷" Hyperlink 或确认对话框）是最终提交，别误触；是否提交由用户决定，用户明确要提交时才执行。
- 提交前可用 `cua_get_window_state` 截图 + 查"已作答"题号，确认**全部题目**都答完（题数以页面实际显示为准）。

## 多空格题目的注意事项

学习通考试里经常有"一个句子里留多个空"的题型，选项往往是"几个格子的组合"（如 `A で、が` / `B に、に` / `C が、に` / `D に、が`）。这类题最容易错，常见坑：

- **先按"惯用搭配"读，不要按"一个空"读**：看到「～役に立つ」要填「役に立つ」的 に；看到「～のために / ～ように」要先确定前一个空是目的/动机，再选后一个空。
- **多个空之间不独立**：一个空选错会连带影响第二个空的语感判断。先逐个空独立判断，再回头核对"整体读一遍是否通顺"。
- **选项的"组合"语义要一起看**：`A で、が` 意味着"第一空填で、第二空填が"，匹配时整组一起读，不要只看第一空。
- **如果题目是读音题**（选项是假名），优先按"读音 + 词形"判断，再回头看整句是否通顺。
